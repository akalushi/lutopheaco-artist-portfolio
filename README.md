# LUTOPHEACO — Website Assets

This folder contains **placeholders** for the website images. They exist only so
the site looks complete before you add your real artwork. Replace each file
with your own image (same filename, or update the path in `script.js` /
`index.html`) before publishing.

| File | Where it's used | Replace with |
|---|---|---|
| `placeholder-stickers.svg` | Hero collage, portfolio, latest | Your sticker / illustration art |
| `placeholder-book.svg` | Hero collage, portfolio | Storybook cover or spread |
| `placeholder-apparel.svg` | Hero collage, portfolio | T-shirt / merch mockup photo |
| `placeholder-digital.svg` | Hero collage, portfolio | Digital product / printable mockup |
| `placeholder-portrait.svg` | About section | Your portrait or artistic avatar |
| `placeholder-cozy.svg` | Collections — Cozy Little Moods | Collection cover image |
| `placeholder-stories.svg` | Collections — Cozy Little Stories, latest | Collection cover image |
| `placeholder-halloween.svg` | Collections — Spooky & Cute, portfolio | Collection cover image |
| `placeholder-whimsical.svg` | Collections — Whimsical Art, portfolio | Collection cover image |
| `favicon.svg` | Browser tab icon | Your real favicon |
| `og-image-placeholder.png` | Social share image (Open Graph) | 1200×630 px share image |

## Image tips
- Use JPG or WebP photos (lighter than PNG) for artwork; keep SVGs only for
  icons.
- Recommended grid image ratio: **4:3** for portfolio cards, **16:9** for
  collection banners, **1:1** for latest-creation thumbnails.
- Always write descriptive `alt` text when you add real images — update the
  `alt` fields in `SITE_DATA` in `script.js`.
- Only use artwork you own or have permission to use.

## Adding a brand-new placeholder
Any image works as long as the path matches. If you add files here, reference
them from the `image:` fields in `script.js`.
